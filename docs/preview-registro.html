🎯 Características Implementadas

✅ Validación Frontend ✅ Validación Backend ✅ Contraseñas Seguras ✅ PDO Prepared Statements ✅ Diseño Responsive ✅ Campos Únicos ✅ Mensajes de Error ✅ Bootstrap 5

📋 Campos del Formulario

Campo Tipo Validación Obligatorio
Nombres Text Solo letras y espacios, máx 100 caracteres ✅ Sí
Apellidos Text Solo letras y espacios, máx 100 caracteres ✅ Sí
Correo Electrónico Email Formato email válido, único en BD ✅ Sí
Cédula Text Solo números, mín 6 dígitos, única en BD ✅ Sí
Contraseña Password Mínimo 6 caracteres, hasheada con bcrypt ✅ Sí
Confirmar Contraseña Password Debe coincidir con la contraseña ✅ Sí

🗄️ Estructura de Base de Datos

CREATE TABLE users ( id INT AUTO_INCREMENT PRIMARY KEY, nombres VARCHAR(100) NOT NULL, apellidos VARCHAR(100) NOT NULL, email VARCHAR(255) NOT NULL UNIQUE, cedula VARCHAR(20) NOT NULL UNIQUE, username VARCHAR(100) NOT NULL UNIQUE, password VARCHAR(255) NOT NULL, is_admin TINYINT(1) DEFAULT 0, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );

🔒 Seguridad Implementada

🛡️ SQL Injection: Protegido con PDO prepared statements
🔐 Contraseñas: Hasheadas con password_hash() usando bcrypt
🧹 XSS: Sanitización con htmlspecialchars()
✅ Validación Doble: Frontend (UX) + Backend (Seguridad)
🎯 Unicidad: Email y cédula verificados antes de insertar

🎨 Validaciones en Tiempo Real

  • Nombres/Apellidos: Solo se permiten letras y espacios (bloqueo automático de números)
  • Cédula: Solo se permiten números (bloqueo automático de letras)
  • Email: Validación de formato HTML5
  • Contraseñas: Comparación en tiempo real, alerta si no coinciden
  • Feedback visual: Bordes rojos/verdes según validación

📱 Responsive Design

El formulario se adapta perfectamente a:

  • 📱 Móviles: Diseño vertical optimizado

  • 🖥️ Desktop: Tarjeta con sombra, centrada (máx 600px)

🚀 Cómo Usar

Paso 1: Importar la Base de Datos

Abre phpMyAdmin y ejecuta el archivo database/adeshop.sql

Paso 2: Verificar config.php

$DB_HOST = '127.0.0.1'; $DB_NAME = 'adeshop'; $DB_USER = 'root'; $DB_PASS = ''; // Tu contraseña MySQL

Paso 3: Acceder al Formulario

Navega a: http://localhost/ADESHOP/registro.php

💡 Flujo de Registro

  1. Usuario completa el formulario
  2. Validación en tiempo real mientras escribe
  3. Click en "Registrarse"
  4. Validación backend completa
  5. Verificación de email único
  6. Verificación de cédula única
  7. Generación automática de username
  8. Hash de contraseña con bcrypt
  9. Inserción en base de datos
  10. Mensaje de éxito + opciones de navegación

🎯 Username Automático

El sistema genera automáticamente un username único:

juan@email.com → username: "juan" maria@email.com → username: "maria" Si ya existe: juan@email.com → username: "juan1729234567" (con timestamp)
