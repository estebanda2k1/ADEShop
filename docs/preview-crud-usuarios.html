🔒 Seguridad Implementada

SQL Injection

Protegido con PDO Prepared Statements en todas las consultas

XSS Protection

Sanitización con htmlspecialchars() en todas las salidas

Contraseñas Seguras

Hash con password_hash() usando bcrypt (PASSWORD_DEFAULT)

Control de Acceso

Verificación de sesión y permisos en cada página

Validación Doble

Frontend (JavaScript) y Backend (PHP)

Autoprotección

Los admins no pueden eliminarse a sí mismos

📖 Guía de Uso Rápida

1 Acceder al Dashboard
http://localhost/ADESHOP/dashboard.php

Requisito: Estar autenticado como administrador (is_admin = 1)

2 Gestión de Usuarios

En el dashboard, haz clic en la tarjeta "Gestión de Usuarios"

Verás la lista completa de clientes registrados con las siguientes opciones:

  • Buscar por nombre, email o cédula
  • Ver detalles de cada usuario
  • Editar información
  • Eliminar usuarios
  • Exportar a CSV
3 Crear Nuevo Usuario

Haz clic en el botón + Nuevo Usuario

Completa todos los campos requeridos y marca la casilla "Es Administrador" si corresponde

4 Buscar Usuarios

Usa la barra de búsqueda para filtrar por:

  • Nombres
  • Apellidos
  • Email
  • Cédula
